            PAM001
            HIGH
          

          
SQL Injection

          
CWE-89

          
Detects when untrusted user input flows into SQL query strings via f-strings, concatenation, or format calls, then passed to cursor.execute() or equivalent database sinks.

          

            input()
            request.args
            request.form
          

          

            cursor.execute()
            cursor.executemany()
          

        


        

          

            PAM002
            HIGH
          

          
Command Injection

          
CWE-78

          
Tracks tainted data from user-controlled sources reaching OS command execution sinks such as os.system(), subprocess.run(), and subprocess.call().

          

            input()
            sys.argv
            os.environ
          

          

            os.system()
            subprocess.run()
            subprocess.Popen()
          

        


        

          

            PAM003
            CRITICAL
          

          
Unsafe Deserialization

          
CWE-502

          
Identifies cases where untrusted data is passed to pickle.loads(), marshal.loads(), or yaml.load() without safe loaders, enabling remote code execution.

          

            input()
            request.data
            open().read()
          

          

            pickle.loads()
            marshal.loads()
            yaml.load()
          

        

      

    


    
    

      

        
About PyAttackMap

        
High-performance native security analysis for Python codebases

      

      

        

          
Native C++20 Engine

          
Zero Python interpreter runtime overhead. The analysis engine is compiled to native machine code achieving 42x speedup over the Python baseline.

        

        

          
Tree-sitter Parsing

          
Uses the official Tree-sitter C runtime with Python grammar for robust, fast concrete syntax tree parsing without executing target code.

        

        

          
Taint Tracking

          
Intra-procedural def-use data flow analysis that traces untrusted sources to critical sinks, with full propagation path reporting.

        

        

          
Structured Output

          
Deterministic JSON reporting with source coordinates, remediation guidance, confidence scores, and Mermaid attack graph export.
