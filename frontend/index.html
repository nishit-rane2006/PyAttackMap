📋 Security Rules

        
Built-in detection rules powered by intra-procedural taint analysis

            HIGH
          

          
SQL Injection

          
CWE-89

          
Detects when untrusted user input flows into SQL query strings via f-strings, concatenation, or format calls, then passed to cursor.execute() or equivalent database sinks.

          

            input()
            request.args
            request.form
          

          

            cursor.execute()
            cursor.executemany()
          

        


        

          

            PAM002
            HIGH
          

          
Command Injection

          
CWE-78

          
Tracks tainted data from user-controlled sources reaching OS command execution sinks such as os.system(), subprocess.run(), and subprocess.call().

          

            input()
            sys.argv
            os.environ
          

          

            os.system()
            subprocess.run()
            subprocess.Popen()
          

        


        

          

            PAM003
            CRITICAL
          

          
Unsafe Deserialization

          
CWE-502

          
Identifies cases where untrusted data is passed to pickle.loads(), marshal.loads(), or yaml.load() without safe loaders, enabling remote code execution.

          

            input()
            request.data
            open().read()
          

          

            pickle.loads()
            marshal.loads()
            yaml.load()
